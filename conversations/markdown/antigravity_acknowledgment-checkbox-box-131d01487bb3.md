Based on the investigation of the codebase, here are the root causes for the issue where checking the acknowledgment checkbox causes the box (modal dialog or checkbox component) to turn white blank:

---

### 1. Root Causes

#### A. Runtime Crash during Modal Re-render (Modal Box Turns White Blank)
When the acknowledgment checkbox is clicked, the parent component triggers a state update (`setApply(true)` or `setIsDeclarationApproved(true)`). When the component re-renders with the new checked state, an uncaught runtime error causes React to unmount the modal contents:

1. **Unsafe `router.query` Splitting in [`ModalConfirm`](file:///D:/work/qcash-ui-amend-cancel-lc/components/modal-confirm/modal-confirm.tsx#L54-L56)**:
   ```tsx
   const { id } = router.query;
   const refNo: any = id?.toString().split("-");
   const referenceNo = isNewData ? refNo[1].toString() : refNo[2].toString();
   ```
   - If `id` does not have 2 or 3 hyphen-delimited parts (e.g. `refNo[1]` or `refNo[2]` is `undefined`), accessing `.toString()` directly in the render body throws `TypeError: Cannot read properties of undefined (reading 'toString')`.
   - As soon as the checkbox is clicked, the state updates, the component re-renders, crashes, and leaves the modal dialog completely **white blank**.

2. **Unsafe Field Access in Customer Declaration Coverage List in [`CustomerDeclarationModal`](file:///D:/work/qcash-ui-amend-cancel-lc/components/ui/customer-declaration-modal.tsx#L204-L221)**:
   ```tsx
   {renderList(coverageAccounts, (a: any) =>
     /loan|pinjaman|credit|^LN$/i.test(a.accountType)
   )}
   ```
   - If any account entry in `coverageAccounts` has `accountType` as `undefined` or `null`, or if `coverageAccounts` is not a valid array, regex testing or list mapping throws an error during the re-render when `isAgreed` changes.

---

#### B. Dynamic Remote Loading & Structure of Single Checkbox in [`QuiCheckbox`](file:///D:/work/qcash-ui-amend-cancel-lc/components/ui/qui-checkbox.tsx#L44-L69)
If the issue is that the **checkbox square itself** turns white/blank with no checkmark:

1. **Granular `next/dynamic` Remote Component Wrappers in [`global.tsx`](file:///D:/work/qcash-ui-amend-cancel-lc/components/global.tsx#L689-L703)**:
   - `QuiCheckboxPrimitive.Control`, `QuiCheckboxPrimitive.Indicator`, and `QuiCheckboxPrimitive.Content` are each individually wrapped in separate `dynamic(() => loadQuiRemote(...), { ssr: false })` loaders.
   - When transitioning from `checked={false}` to `checked={true}`, the `<QuiCheckboxPrimitive.Indicator />` needs to render the remote checkmark SVG. If the indicator fails to resolve its icon or style context across the dynamic boundary, the checkbox renders as an empty white box.
2. **Single Checkbox Nested Inside `CheckboxGroup`**:
   - [`QuiCheckbox`](file:///D:/work/qcash-ui-amend-cancel-lc/components/ui/qui-checkbox.tsx#L49-L68) wraps single checkboxes inside `QuiCheckboxGroup` with array conversion (`[checkboxValue]`) instead of passing `isSelected` and `onChange` directly to `QuiCheckboxPrimitive`.
