### 2. TanStack React Query Client Singleton ([services/query-client.ts](file://~/Development/qcash-ui-manual-token-verification/services/query-client.ts))

```typescript
let browserQueryClient: QueryClient | undefined;

export function getQueryClient() {
  if (globalThis.window === undefined) {
    // Server: always make a new query client
    return makeQueryClient();
  }
  // Browser: make a new query client if we don't already have one
  browserQueryClient ??= makeQueryClient();
  return browserQueryClient;
}
```

#### **Status: Excellent**
* Follows the **official TanStack Query SSR / Next.js best practices**:
  * **Server-side (SSR):** Returns a new `QueryClient` instance per request to prevent cross-request memory leaks and data leakage between users.
  * **Client-side (Browser):** Enforces a true singleton (`browserQueryClient ??= makeQueryClient()`) across all component renders and micro-frontend remote boundaries.
