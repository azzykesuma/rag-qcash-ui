### Why the Error Happens

The error:
```text
container entry
Module not found: originalExternals is not a function
```
occurs when Webpack compiles the Module Federation **Container Entry** (the virtual entry point that exposes and manages shared dependencies) during server-side build/compilation (`isServer: true`), and `@module-federation/nextjs-mf` attempts to intercept Next.js's default `externals` resolver.

---

### Root Cause Breakdown

#### 1. How `@module-federation/nextjs-mf` patches Next.js Server Externals
In Next.js server builds, `node_modules` are treated by default as Webpack **externals** (loaded via Node's `require` instead of bundled). However, for Module Federation to share packages (e.g. `@ordentco/addons-auth-provider`, `react`, `ni18n`) across federated remotes during SSR, `nextjs-mf` needs to internalize those shared modules.

To achieve this, `nextjs-mf` hooks into the server compiler via [`apply-server-plugins.js`](file:///D:/work/qcash-ui/node_modules/@module-federation/nextjs-mf/dist/src/plugins/NextFederationPlugin/apply-server-plugins.js#L100-L107):

```javascript
if (Array.isArray(compiler.options.externals) && compiler.options.externals[0]) {
  const originalExternals = compiler.options.externals[0];
  compiler.options.externals[0] = async function (ctx, callback) {
    const fromNext = await originalExternals(ctx, callback); // 💥 Fails here if not a function
    // ...
  };
}
```

#### 2. Why `originalExternals` is Not a Function
Webpack allows `compiler.options.externals` to contain objects, regexes, strings, or functions (`Array<string | RegExp | Object | Function>`).

`originalExternals is not a function` is thrown when `compiler.options.externals[0]` is **an object, string, or undefined** instead of Next.js's expected external resolver function. This typically happens due to:

1. **`config.target = "web"` applied to the Server Build**:
   If `next.config.js` sets `config.target = "web"` globally without checking `if (!isServer)`, Next.js disables its server-side external resolver logic. As a result, `externals[0]` is either missing, replaced with a non-function, or structured for client bundling.

2. **Custom `config.externals` modification in `next.config.js`**:
   If another Webpack plugin or custom code in `next.config.js` prepends or replaces `config.externals` (e.g. `config.externals = [{ ... }, ...]`), `externals[0]` becomes an object. When `nextjs-mf` executes `await originalExternals(ctx, callback)`, JavaScript throws `TypeError: originalExternals is not a function`.

3. **`NEXT_PRIVATE_LOCAL_WEBPACK=true` missing or mismatched Webpack version**:
   If Next.js runs its internal pre-compiled Webpack (`next/dist/compiled/webpack`) instead of local `webpack@5`, Next's internal externals hook structure differs from what `nextjs-mf` expects.

---

### How to Fix It

#### 1. Restrict `config.target = "web"` to the Client Only
In [`next.config.js`](file:///D:/work/qcash-ui/next.config.js#L146-L152) and remote configs:

```javascript
webpack: (config, options) => {
  const { isServer, dev } = options;

  // ✅ Only set web target for client builds
  if (!isServer) {
    config.target = "web";
    config.parallelism = 6;
  }

  // ...
  config.plugins.push(new NextFederationPlugin(federationConfig));
  return config;
}
```

#### 2. Ensure `NEXT_PRIVATE_LOCAL_WEBPACK=true` is present
Make sure the dev/build script has:
```powershell
$env:NEXT_PRIVATE_LOCAL_WEBPACK="true"; yarn next dev
```

#### 3. Keep `config.externals` array types clean
If you need custom externals in `next.config.js`, append them or ensure functions are preserved:
```javascript
if (typeof config.externals === 'function') {
  config.externals = [config.externals];
}
```

### Why `originalExternals is not a function` was happening in `qcash-ui-issuance-lc`

1. **Next.js 14 `externals` Array Structure**:
   In `qcash-ui-issuance-lc`, Next.js is running version `14.2.35`. In Next 14.2+, Next.js changed its server-side Webpack `externals` configuration into an array where:
   * **`compiler.options.externals[0]`** is an **Object** containing internal Next.js pre-compiled packages (e.g. `jest-worker`, etc.).
   * **`compiler.options.externals[1]`** is the **Function** (`handleExternals`) that resolves runtime externals.

2. **`@module-federation/nextjs-mf` Assumption**:
   [`apply-server-plugins.js`](file:///D:/work/qcash-ui-issuance-lc/node_modules/@module-federation/nextjs-mf/dist/src/plugins/NextFederationPlugin/apply-server-plugins.js#L100-L107) directly indexed `compiler.options.externals[0]` assuming it was a function:
   ```javascript
   const originalExternals = compiler.options.externals[0]; // ❌ Picked up the Object instead of the function
   compiler.options.externals[0] = async function (ctx, callback) {
     const fromNext = await originalExternals(ctx, callback); // 💥 TypeError: originalExternals is not a function
   };
   ```

---

### Solutions Applied

1. **Reordered `config.externals` in [`qcash-ui-issuance-lc/next.config.js`](file:///D:/work/qcash-ui-issuance-lc/next.config.js#L76-L88)**
   Ensured the resolver function is positioned at index 0 before `NextFederationPlugin` hooks into it:
   ```javascript
   if (isServer && Array.isArray(config.externals)) {
     const fnIndex = config.externals.findIndex((e) => typeof e === "function");
     if (fnIndex > 0) {
       const [fn] = config.externals.splice(fnIndex, 1);
       config.externals.unshift(fn);
     }
   }
   ```

2. **Added Resolve Aliases in [`qcash-ui-issuance-lc/next.config.js`](file:///D:/work/qcash-ui-issuance-lc/next.config.js#L76-L80)**
   Added explicit module aliases for `@module-federation/sdk` and `@module-federation/runtime` to prevent nested resolver recursion.

3. **Patched [`optional-peer-dependency-resolve-plugin.js`](file:///D:/work/qcash-ui-issuance-lc/node_modules/next/dist/build/webpack/plugins/optional-peer-dependency-resolve-plugin.js#L11-L15)**
   Prevented `_resolveContext_stack.delete is not a function` during Webpack 5 module resolution.

### Runtime Analysis & Resolution

The runtime error encountered:
```text
fetching http://internal-service.example.com/global-component/_next/static/chunks/remoteEntry.js
fetching http://internal-service.example.com/design-system/static/remoteEntry.js
⨯ Error: Script execution error: Error: Automatic publicPath is not supported in this browser
    at eval (webpack-internal:///./node_modules/@module-federation/sdk/dist/index.cjs.js:1140:36)
```

---

### Root Cause

1. **Client-side Chunk Execution on Node.js Server (SSR)**:
   * When Next.js renders on the server, `@module-federation/sdk` fetches the remote entry files and executes them in Node.js via `vm.Script`.
   * Because `qcash-global-component` and `qui` remotes were pointing directly to client bundles (`static/chunks/remoteEntry.js`), Webpack's automatic publicPath code (`publicPath: "auto"`) searched for `document.currentScript`.
   * In a Node.js server environment, `global.document` is `undefined`, so Webpack threw `Error: Automatic publicPath is not supported in this browser`.

2. **Missing SSR / Client Remote Differentiation**:
   * Next.js remotes (like `qcash-global-component`) generate two different bundles:
     * **Client:** `/global-component/_next/static/chunks/remoteEntry.js`
     * **Server (SSR):** `/global-component/_next/static/ssr/remoteEntry.js`
   * Static/pure-client remotes like `qui` do not have an SSR bundle and require a `global.document` fallback during Node-side evaluation.

---

### Fixes Implemented

1. **`global.document` Node Runtime Fallback** in [`qcash-ui-issuance-lc/next.config.js`](file:///D:/work/qcash-ui-issuance-lc/next.config.js#L19-L27):
   ```javascript
   if (typeof global !== "undefined" && typeof global.document === "undefined") {
     const envDomain = process.env.ENV_DOMAIN || "http://internal-service.example.com";
     global.document = {
       currentScript: { src: `${envDomain}/` },
       getElementsByTagName: () => [{ src: `${envDomain}/` }],
     };
   }
   ```

2. **Dynamic `isServer` Remote Location** in [`qcash-ui-issuance-lc/next.config.js`](file:///D:/work/qcash-ui-issuance-lc/next.config.js#L29-L38):
   ```javascript
   const getFederationConfig = (isServer) => {
     const location = isServer ? "ssr" : "chunks";
     return {
       // ...
       remotes: {
         "qcash-global-component": `qcash-global-component@${process.env.ENV_DOMAIN}/global-component/_next/static/${location}/remoteEntry.js`,
         qui: `qui@${process.env.ENV_DOMAIN}/design-system/static/remoteEntry.js`,
       },
     };
   };
   ```
