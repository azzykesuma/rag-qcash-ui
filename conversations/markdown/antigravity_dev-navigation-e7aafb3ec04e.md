## Turn 58: Assistant

Here is the exact reason why the monkey patch works on **dev** (`gym-master`) but fails on **prerelease** (`internal-service.example.com`):

---

### Root Cause Summary

On the `prerelease` branch, **[`MenuModalProvider.tsx`](file:///D:/work/qcash-ui-header-footer/layouts/default/container/menu/components/MenuModalProvider.tsx) is completely unused (dead code).** 

The monkey patch was added to [`MenuModalProvider.tsx`](file:///D:/work/qcash-ui-header-footer/layouts/default/container/menu/components/MenuModalProvider.tsx#L86-L93):
```tsx
// MenuModalProvider.tsx
const handleNavigation = useMemoizedFn((href: string) => {
  if (globalThis.window.location.pathname.startsWith("/v2/import-lc/issuance-lc")) {
    console.log("here")
    // A document navigation guarantees the federated issuance page is unmounted.
    globalThis.window.location.href = href;
    return;
  }
  ...
```

However, **[`Menu.tsx`](file:///D:/work/qcash-ui-header-footer/layouts/default/container/menu/components/Menu.tsx) on `prerelease` never imports or renders `MenuModalProvider`**. 

Instead, `prerelease` has an older, monolithic version of `Menu.tsx` with its own internal navigation handler that calls `router.push`:

---

### Detailed Comparison: Dev vs Prerelease

#### 1. On `dev` (`origin/dev`) — **Working**
[`layouts/default/container/menu/components/Menu.tsx`](file:///D:/work/qcash-ui-header-footer/layouts/default/container/menu/components/Menu.tsx) was refactored to delegate all modal and menu clicks to [`MenuModalProvider`](file:///D:/work/qcash-ui-header-footer/layouts/default/container/menu/components/MenuModalProvider.tsx):

```tsx
// origin/dev: Menu.tsx
import { MenuModalProvider, useMenuModal } from "./MenuModalProvider";

const MenuContent = () => {
  const menu = useMenu();
  const { onMenuClick } = useMenuModal();

  return (
    <MenuMapper
      items={menu?.data?.menu}
      loading={menu?.loading || false}
      mapper={menu?.data?.mapper}
      onItemClick={onMenuClick}
    />
  );
};

export const Menu = () => {
  return (
    <div className={`hf-min-h-[46px] ...`}>
      <MenuModalProvider>
        <MenuContent />
      </MenuModalProvider>
    </div>
  );
};
```
When a user clicks a menu on `dev`, [`MenuModalProvider`](file:///D:/work/qcash-ui-header-footer/layouts/default/container/menu/components/MenuModalProvider.tsx)'s `handleNavigation` is invoked, hits `pathname.startsWith("/v2/import-lc/issuance-lc")`, and triggers a hard document navigation (`window.location.href = href`), successfully unmounting the federated page.

---

#### 2. On `prerelease` — **Failing**
On the `prerelease` branch, [`Menu.tsx`](file:///D:/work/qcash-ui-header-footer/layouts/default/container/menu/components/Menu.tsx#L48-L107) does **not** use `MenuModalProvider`. It defines its own internal navigation handler:

```tsx
// prerelease: Menu.tsx
  const handleRedirect = useMemoizedFn((menuData: any) => {
    ...
    if (isV2Href) {
      if (isV2Current) {
        const _href = href.split("/").slice(2).join("/");
        go(`/${_href}`); // <--- calls router.push()!
      } else {
        go(href || "/homepage");
      }
      return;
    }
    ...
```

Because `go` is `router.push`, Next.js only performs client-side history navigation (`pushState`). The URL changes in the browser address bar, but the federated `issuance-lc` microfrontend does not unmount. The patch in `MenuModalProvider.tsx` is never reached because `MenuModalProvider` is not rendered anywhere on `prerelease`.

---

### Solution Options

1. **Align `Menu.tsx` with `dev` (Recommended):**
   Update [`Menu.tsx`](file:///D:/work/qcash-ui-header-footer/layouts/default/container/menu/components/Menu.tsx) on `prerelease` to match `origin/dev`, wrapping `<MenuContent />` inside `<MenuModalProvider>`.
2. **Patch `Menu.tsx` directly:**
   If `prerelease` is keeping the legacy `Menu.tsx` implementation, add the same monkey patch into `handleRedirect` inside [`Menu.tsx`](file:///D:/work/qcash-ui-header-footer/layouts/default/container/menu/components/Menu.tsx#L89-L94) before `isV2Href` check:
   ```tsx
   if (globalThis.window.location.pathname.startsWith("/v2/import-lc/issuance-lc")) {
     globalThis.window.location.href = href;
     return;
   }
   ```
