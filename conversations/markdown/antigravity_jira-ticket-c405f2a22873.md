### Why the Work Log is Empty

In Jira, Bitbucket integrations automatically link your **branches, commits, and pull requests** into the **"Development"** panel on the right sidebar, but Jira **never creates Work Logs automatically** from Git/Bitbucket activities. 

Work logs track time spent against estimates and must be recorded explicitly.

---

### How to Add Work Logs

You can add work logs in two ways:

#### Option 1: Directly in the Jira Web UI (Recommended)
1. Open the ticket: [NQLA-74717](https://internal-service.example.com/browse/NQLA-74717) (or parent [NQLA-74455](https://internal-service.example.com/browse/NQLA-74455)).
2. Under the issue header, click **"..." (More actions)** or press the keyboard shortcut **`w`**.
3. Select **"Log Work"**.
4. Fill in:
   - **Time Spent**: e.g., `4h`, `1d`, `2h 30m`
   - **Date Started**: Select the date and start time
   - **Work Description**: Brief note on what was completed (e.g., *“Pruned /main-page redirection across qcash-ui, header-footer, and global-component, created dev and prerelease PRs”*)
5. Click **Log**.

---

#### Option 2: Let Antigravity Log It via API
If you'd like me to log the work for you directly through the Jira API, please specify:
- **Target Ticket**: `NQLA-74717` (subtask) or `NQLA-74455` (parent)
- **Time Spent**: (e.g., `4h`, `1d 2h`, etc.)
- **Date Started**: (e.g., today, or backdated to Oct 14 / Oct 19)
- **Work Description**: (or I can auto-generate a summary of the PR tasks)
