This issue happens because **the route and breadcrumb mappings for `dashboard-auto-collection` exist in `dev`, but were never merged or cherry-picked into the `prerelease` branch**.

---

### Root Cause Analysis

1. **Missing Commit on `prerelease`**:
   The feature was implemented in commit [`5918f6c3`](file:///D:/work/qcash-ui-header-footer) / **PR #535** (`52122a9c`: *feat: add dashboard auto collection route and breadcrumb mapping*) and merged into `dev`.
   
   The following changes exist in `dev`, but are **missing from `prerelease`**:
   - [`features/other-modules/dashboard-auto-collection.route.ts`](file:///D:/work/qcash-ui-header-footer/features/other-modules/dashboard-auto-collection.route.ts) (new route definition)
   - [`features/other-modules/index.ts`](file:///D:/work/qcash-ui-header-footer/features/other-modules/index.ts) (exporting `dashboardAutoCollectionRoutes`)
   - [`features/routeMappings.tsx`](file:///D:/work/qcash-ui-header-footer/features/routeMappings.tsx) (mapping `{ paths: ["/dashboard-auto-collection"], breadcrumb: "Ecosystem" }`)

2. **Runtime Execution on `prerelease`**:
   When navigating to `/v2/dashboard-auto-collection` on `prerelease`:
   - In [`getCurrentRoutes`](file:///D:/work/qcash-ui-header-footer/layouts/default/container/breadcrumb/utils/useRouterPathV2.tsx#L30-L43):
     - `routeModules.find(...)` cannot find any module handling `/dashboard-auto-collection` $\rightarrow$ **`activeModule: undefined`**, **`baseRoutes: []`**.
     - [`renderBreadcrumbs`](file:///D:/work/qcash-ui-header-footer/layouts/default/container/breadcrumb/utils/useRouterPathV2.tsx#L15-L22) checks [`routeMappings`](file:///D:/work/qcash-ui-header-footer/features/routeMappings.tsx), which has no entry for `/dashboard-auto-collection` $\rightarrow$ **`prefix: ""`**.
     - `getCurrentRoutes` returns **`currentRoutes: []`**.
   - In [`Breadcrumb.tsx`](file:///D:/work/qcash-ui-header-footer/layouts/default/container/breadcrumb/components/Breadcrumb.tsx#L37-L39):
     ```tsx
     if (!currentRoutes.length) {
       return null;
     }
     ```
     Since `currentRoutes` is empty, the component returns `null` and renders nothing.

---

To resolve this on the prerelease environment, cherry-pick commit `5918f6c3df6b150cd8ae9927c22d5ee56ecdb024` into `prerelease`:
