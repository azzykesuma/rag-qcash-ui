Berdasarkan analisis terhadap dokumentasi migrasi **i18n (Legacy to Centralized API-Based System)** pada platform QCASH/QLola serta perbandingannya dengan codebase di repository **`qcash-ui-dashboard-auto-collection`**, berikut adalah analisis dan kesimpulannya:

---

### 1. Inti dari Dokumentasi Migrasi i18n (*Centralized API-Based System*)

Arsitektur migrasi i18n QCASH berbasis *Zero-Friction Module Migration* mengharuskan:
1. **Modular Namespace**: Tidak lagi menumpuk semua string di satu file monolitik global (`translation.json`), melainkan memisahkan per modul (misal: `dashboard-auto-collection`) dan *fallback* ke `common`.
2. **Key Naming Convention & Dot Notation**: Menggunakan format penamaan terstruktur (`module/component.element.action_or_state` seperti `dashboardAcs.header.periodLabel`, `button.refresh`, `table.column.*`).
3. **Locale Parity**: Kunci (*keys*) antara bahasa `en` dan `id` harus 100% konsisten/paritas.
4. **Standalone & Host Compatibility**: Modul memiliki *fallback local bundle* (`public/locales/{en,id}/*.json`) dan menyuntikkan bundle ke instance i18next (`ensureDashboardAutoCollectionResources`) sehingga berfungsi mandiri saat *local development* maupun saat di-mount oleh shell `qcash-ui`.
5. **Host Registration**: Namespace didaftarkan di host `qcash-ui` pada file `constants/features/registry.ts` melalui properti `i18n: ["<namespace>"]` agar `i18next-http-backend` di Host dapat mengambil string dinamis dari API `GET /api/language/v1/translations?lang={lang}&module={module}`.

---

Berdasarkan analisis dokumen **Header Footer Breadcrumbs - Developer Quickstart** dan arsitektur micro-frontend QCASH, berikut adalah analisis kesesuaian implementasi di repository **`qcash-ui-dashboard-auto-collection`**:

---

### 1. Inti dari Praktik & Standar *Header Footer Breadcrumbs*

Dalam arsitektur micro-frontend QLola/QCASH:
1. **Sentralisasi Breadcrumb di Shell / Header-Footer**:
   Komponen `<Breadcrumb />` tidak lagi dirender secara terpisah di dalam *body* masing-masing micro-frontend (remote MFE). Komponen tersebut dikelola dan dirender secara terpusat oleh **`qcash-ui-header-footer`** di bagian atas layout host (`qcash-ui`).
2. **Dynamic Route Matching**:
   Header-footer membaca `router.pathname` dan menentukan hierarki breadcrumb menggunakan implementasi `FeatureRouteModule` (`handles`, `subPaths`, dan `getBreadcrumbs` menggunakan `routeMatcher`).
3. **Prefix Mapping (`routeMappings.tsx`)**:
   Prefix kategori modul (misalnya `Ecosystem > Port Solution` atau `Master`) dipetakan secara terpusat di `features/routeMappings.tsx` pada repo `qcash-ui-header-footer`.
4. **No In-Page Breadcrumbs in Remote MFE**:
   Remote MFE bertanggung jawab menyajikan konten fitur utama dan **tidak boleh me-render breadcrumb ganda** di dalam halamannya.

---

### 2. Evaluasi Implementasi pada Modul `qcash-ui-dashboard-auto-collection`

Modul ini **SUDAH MENGIKUTI PRAKTIK TERSEBUT**:

### 3. Langkah yang Perlu Dilakukan di Repo `qcash-ui-header-footer` (Saat Integrasi Shell)

Sesuai dengan *Developer Quickstart*, agar breadcrumb untuk Dashboard Auto Collection muncul di header navigasi saat diakses melalui host:

1. **Buat Route Handler di `qcash-ui-header-footer`** (misal: `features/port-solution/dashboard-auto-collection.route.ts`):
   ```typescript
   import { FeatureRouteModule } from "@/features/types";
   import { CrudBreadcrumbs, routeMatcher } from "@/features/route-helpers";

   const ROOT_PATH = "/dashboard-auto-collection-v2";
   const ROOT_LABEL = "Dashboard Auto Collection";

   export const dashboardAutoCollectionRoutes: FeatureRouteModule = {
     handles: (pathname: string) => pathname.startsWith(ROOT_PATH),
     subPaths: [ROOT_PATH],
     getBreadcrumbs: (router) => {
       return routeMatcher()
         .match(ROOT_PATH, () => CrudBreadcrumbs.list(ROOT_LABEL))
         .getBreadcrumbs(router.pathname);
     },
   };
   ```
2. **Tambahkan Prefix Mapping di `features/routeMappings.tsx`**:
   Tambahkan mapping path ke prefix `Ecosystem > Port Solution` jika ada kategori menu induknya.
3. **Daftarkan di `features/modules.ts`**:
   Masukkan `...dashboardAutoCollectionRoutes` ke dalam array `routeModules`.
