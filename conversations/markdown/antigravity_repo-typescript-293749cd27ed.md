### Why This Specific Repo Failed to Infer the Type

The root cause was **`declarations.d.ts`**:
- It contained `declare module "@bri/addons-auth-provider";`.
- When an ambient module declaration (`declare module "..."`) is present in the project, TypeScript **shadows and discards** the real `.d.ts` type definitions shipped by the npm package in `node_modules/@bri/addons-auth-provider/dist/src/index.d.ts`.
- As a result, TypeScript treated `@bri/addons-auth-provider` and all of its exports as untyped `any` namespace values rather than interfaces, triggering:
  ```text
  Type error: Cannot use namespace 'AuthProviderProps' as a type.
  ```
- Removing `declarations.d.ts` restored the package's native TypeScript typings, allowing `router={router as AuthProviderProps["router"]}` to be typed and inferred properly, exactly like in the other repos.
