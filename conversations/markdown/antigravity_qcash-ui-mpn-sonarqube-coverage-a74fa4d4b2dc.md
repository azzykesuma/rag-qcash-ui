### 1. Temuan Utama pada Branch `v0.0.0-release` (Penyebab Quality Gate FAILED)

Pada branch **`v0.0.0-release`** yang baru saja dianalisis oleh Bamboo CI (**2 September 2026 pukul 21:42 WIB**), status Quality Gate bernilai **ERROR / FAILED**:

* **Kondisi Gagal:** `Coverage on New Code < 65%`
* **Coverage on New Code:** **`0.0%`**
* **Lines to Cover:** **1 baris**
* **Uncovered Lines:** **1 baris**

#### Penyebab Spesifik (File & Baris):
Di PR #121 (commit [`ef836e5`](file://~/Development/qcash-ui-mpn/next.config.js#L1)), terdapat perubahan penambahan 1 baris kode pada [next.config.js](file://~/Development/qcash-ui-mpn/next.config.js):
```javascript
process.env.NEXT_PRIVATE_LOCAL_WEBPACK = "true";
```

1. **Jest Tidak Menguji `next.config.js`:**
   Pada [jest.config.js](file://~/Development/qcash-ui-mpn/jest.config.js#L17-L45), `collectCoverageFrom` hanya mengumpulkan coverage untuk folder `components/`, `utils/`, `containers/`, `pages/`, `hooks/`, dan `services/`. File konfigurasi seperti `next.config.js` tidak diuji oleh Jest dan tidak masuk ke `coverage/lcov.info`.
2. **`next.config.js` Tidak Masuk ke `sonar.coverage.exclusions`:**
   Pada [sonar-project.properties](file://~/Development/qcash-ui-mpn/sonar-project.properties#L10), konfigurasinya adalah:
   ```properties
   sonar.exclusions=**/*.test.ts,**/*.test.tsx,**/__tests__/**,**/node_modules/**,**/.next/**,**/coverage/**,**/styles/**,**/*.d.ts,next.config.js,jest.setup.ts
   sonar.coverage.exclusions=components/qui/**
   ```
   * File `next.config.js` **tidak didaftarkan di `sonar.coverage.exclusions`**.
   * Di `sonar.exclusions`, penulisan `next.config.js` (tanpa wildcard `**/next.config.js`) sering kali tidak ter-match jika scanner dijalankan dari root atau dioverride parameter CLI CI.
   * Akibatnya, SonarQube menganggap 1 baris baru di [next.config.js](file://~/Development/qcash-ui-mpn/next.config.js#L1) sebagai kode produksi yang harus memiliki unit test. Karena hits = 0, perhitungannya menjadi **`0 / 1 = 0.0% Coverage on New Code`**.

  * Pada pipeline `master` saat itu, file laporan unit test (`coverage/lcov.info`) tidak dibuat atau tidak terbaca oleh SonarQube scanner saat build berlangsung.
* **Branch `dev` (Normal / PASS):**

  * Overall coverage: **44.3%**, dan New Code Coverage: **79.2%** (Quality Gate **OK**).

---

### 3. Solusi untuk Memperbaiki

Agar `next.config.js` dan file konfigurasi lainnya tidak dianggap sebagai target coverage oleh SonarQube, perbarui [sonar-project.properties](file://~/Development/qcash-ui-mpn/sonar-project.properties):

```properties
sonar.projectKey=qcash-ui-mpn
sonar.projectName=QCASH - UI MPN

sonar.sources=components,utils,containers

sonar.tests=components,utils,containers
sonar.test.inclusions=**/*.test.ts,**/*.test.tsx,**/__tests__/**

sonar.exclusions=**/*.test.ts,**/*.test.tsx,**/__tests__/**,**/node_modules/**,**/.next/**,**/coverage/**,**/styles/**,**/*.d.ts,**/next.config.js,**/jest.setup.js,**/jest.config.js
sonar.coverage.exclusions=components/qui/**,**/next.config.js,**/jest.config.js,**/jest.setup.js,**/*.config.js

sonar.sourceEncoding=UTF-8

sonar.javascript.lcov.reportPaths=coverage/lcov.info
sonar.typescript.lcov.reportPaths=coverage/lcov.info

sonar.projectBaseDir=.
```

Setelah menambahkan `**/next.config.js,**/*.config.js` ke `sonar.coverage.exclusions`, silakan commit dan trigger ulang pipeline Bamboo agar SonarQube tidak lagi menghitung baris di `next.config.js`.
