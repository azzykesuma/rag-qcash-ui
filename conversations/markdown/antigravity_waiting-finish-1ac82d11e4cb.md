   ```tsx
   it("should render UnauthorizedDialog when authority is undefined", () => {
     mockUseAuth.mockReturnValue({
       isAuthoritiesReady: true,
       token: "token",
       username: "user1",
       userType: "cu",
       productAuthorities: { DO_SEMEN_INDONESIA: undefined }, // <-- authority bernilai undefined
     });

     render(<DOSemenIndonesiaCreatePage />);
     expect(screen.getByTestId("unauthorized-dialog")).toBeTruthy();
   });
   ```

2. **Runtime TypeError tanpa `?.`**:
   Di [pages/do-semen-indonesia/create-transaction/index.tsx](file:///D:/work/qcash-ui-do-semen-indonesia/pages/do-semen-indonesia/create-transaction/index.tsx):
   ```tsx
   const authority = productAuthorities.DO_SEMEN_INDONESIA; // undefined
   const haveAuthority = authority.batch; // ❌ TypeError: Cannot read properties of undefined (reading 'batch')

   if (!authority || !haveAuthority || ...) return <UnauthorizedDialog />;
   ```
   Karena `authority` bernilai `undefined`, pemanggilan langsung `authority.batch` melempar runtime error sebelum sempat masuk ke pengecekan `if (!authority ...)`, sehingga test suite `create-transaction/index.test.tsx` gagal (*failed*).
