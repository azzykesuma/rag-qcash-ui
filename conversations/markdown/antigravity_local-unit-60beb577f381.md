### 3. Remediation

1. **Add optional chaining in [`hooks/use-translate.ts`](file:///C:/Work/qcash-ui-account-receivable/hooks/use-translate.ts):**
   ```ts
   // In hooks/use-translate.ts
   const [lang, setLang] = React.useState<string>(() => {
     const stored =
       typeof window !== "undefined"
         ? window.localStorage.getItem("locale")
         : null;
     return normalizeLang(stored || i18n?.language);
   });

   React.useEffect(() => {
     const syncLang = () => {
       const stored =
         typeof window !== "undefined"
           ? window.localStorage.getItem("locale")
           : null;
       const next = normalizeLang(stored || i18n?.language);
       setLang(next);
       if (stored && i18n?.language !== next && i18n?.changeLanguage) {
         i18n.changeLanguage(next);
       }
     };
     syncLang();
     window.addEventListener("ADDONS_CHANGE_LANGUAGE", syncLang);
     window.addEventListener("storage", syncLang);
     return () => {
       window.removeEventListener("ADDONS_CHANGE_LANGUAGE", syncLang);
       window.removeEventListener("storage", syncLang);
     };
   }, [i18n, i18n?.language]);
   ```

2. **Retain backward compatibility in [`components/local/table/multipleActionColumn.tsx`](file:///C:/Work/qcash-ui-account-receivable/components/local/table/multipleActionColumn.tsx):**
   Export both `useMultipleActionColumn` and `multipleActionColumn` (or update unit tests and component mocks to export both).

3. **Add `useTranslate` to `@/hooks` test mocks:**
   In the 7 affected test files mocking `@/hooks`:
   ```ts
   jest.mock("@/hooks", () => ({
     ...
     useTranslate: () => ({ t: (k: string) => k, language: "en" }),
   }));
   ```

4. **Defend against undefined `ReceivableChargeType` in [`constants/common.ts`](file:///C:/Work/qcash-ui-account-receivable/constants/common.ts):**
   ```ts
   label: ReceivableChargeType?.Customer ?? "Customer",
   value: ReceivableChargeType?.Customer ?? "Customer",
   ```

5. **Update assertion expectations in `table-pure.test.ts`** to match the translation keys returned by `validateOtp` (`"error.otp.encrypt"`, `"validation.otp.empty"`, etc.).
